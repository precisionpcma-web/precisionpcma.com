Build questions

More answers on the FAQ page.

What's lifetime build support?

Every custom build includes free troubleshooting and diagnosis, help with manufacturer warranty claims (RMAs), a yearly dust-out, and driver and BIOS updates for as long as the original owner has the PC. Replacement parts aren't included unless the manufacturer's warranty covers them, and the travel fee still applies outside Greenfield.

Can I use parts I already have?

Yes. Tick them on the build form and add model numbers if you know them. We'll check they're compatible and plan the build around them. Older parts get tested before we build, and if one isn't up to the job, we'll tell you before anything is ordered.

Can I cancel a custom build?

Yes. If you ordered the parts, you own them, so you can cancel any time before we start building at no charge. If we ordered them for you, the parts are yours and their cost and the $25 handling fee aren't refundable, but labor and add-ons are refunded if we haven't started building. You can take the parts, or we'll try to return them and pass along whatever the store refunds, minus restocking fees and return shipping.
